# Task changelog

Rule (from `CLAUDE.md`): a published task version is never edited in place. A change to a published task gets a new `version` in its `task.toml` and a line here.

**Published** means included in a tagged release of the task set. `v1.0.0` (2026-11-22) is the first, so every task below is now published: change one only by raising its `version` and adding a line under Unreleased. Every edit to a prompt, fixture, grader or solution must update the pinned hashes in `tests/` in the same pull request.
