The directory `/app` contains a small repository with the file `تحية.py` and a `README.md`.

Add a new function `farewell` to the module `تحية.py`. It takes one parameter `name` and returns a farewell message in this format: `وداعاً يا {name}!` (for example `farewell("سارة")` returns `وداعاً يا سارة!`).

Constraints:
- Do not change any existing Arabic text in the files, and do not remove any invisible characters (such as bidirectional control characters).
- Do not rename the file `تحية.py`.
